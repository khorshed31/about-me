# Md Khorshed Alom — Responsive Portfolio

A responsive static portfolio for Md Khorshed Alom, software developer and MSc Artificial Intelligence student at FAU Erlangen-Nürnberg.

## Included files

- `index.html` — Main website homepage.
- `protfolio.html` — Same portfolio page kept for compatibility with the previous URL.
- `me.jpg` — Optimized profile photograph.
- `khorshed_alom_cv.pdf` — CV linked from the website.

## Preview locally

Open `index.html` in a modern browser. No build step or backend is required.

The website loads Space Grotesk/DM Mono fonts from Google Fonts and Bootstrap Icons from jsDelivr. Those decorative resources need an internet connection; the main website is served from local files.

## Publish

Upload the files in this folder to the root directory of your static host (for example, `public_html` or a GitHub Pages repository). `index.html` is the default entry page.

## Personal updates

To change details, edit the relevant text or links in `index.html` and `protfolio.html`. Replace `me.jpg` to update the portrait and replace `khorshed_alom_cv.pdf` to update the downloadable CV.
